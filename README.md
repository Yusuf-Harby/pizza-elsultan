# Pizza El Sultan

تطبيق Java Console ينفّذ الكلاسات والعلاقات في
`diagrams/Pizza-ElSultan-Final-UML-class-diagram.png`.
لا يحتاج مكتبات خارجية أو قاعدة بيانات. البيانات تعيش أثناء التشغيل فقط.

## التشغيل

من جذر المشروع، باستخدام JDK 17 أو أحدث:

```bash
javac -d out src/*.java
java -cp out Main
```

يمكن أيضًا تشغيل `src/Main.java` من IntelliJ IDEA.
قائمة الكونسول بالإنجليزية، وتدعم إنشاء طلب باسم العميل ورقم الهاتف،
واختيار الاستلام أو التوصيل، وإضافة البيتزا والمشروبات والإضافات، وحذف الأصناف،
والدفع، وطباعة الإيصال، وتحديث حالة الطلب أو إلغائه.

## الكلاسات

| الجزء | الكلاسات |
| --- | --- |
| العميل والطلب | `Customer`, `Order`, `OrderItem` |
| الأصناف | `Sellable` (abstract), `Pizza`, `Drink`, `Topping` |
| التسعير والتوصيل والإيصال | `PricingService`, `DeliveryService`, `ReceiptPrinter` |
| الدفع | `PaymentMethod` (interface), `CashPayment`, `CardPayment` |
| الإشعارات | `CustomerNotifier` (interface), `SmsNotifier` |
| التعدادات | `OrderStatus`, `FulfillmentType`, `PizzaSize`, `PaymentResult` |

الأسماء المكتملة في الكود تقابل العناوين المقطوعة بصريًا في الصورة.
`Main` يشغّل الكونسول، و`Validation` مساعد للتحقق من المدخلات.
كل الكلاسات في الـ default package لتناسب هيكل المشروع الحالي.

## قواعد التنفيذ

الرسم لا يحدد أسعار المنيو أو نسب الخصم أو زمن التوصيل؛ القيم التالية افتراضات قابلة للتعديل:

- الأسعار بالجنيه المصري. سعر البيتزا الأساسي للحجم الصغير؛ المتوسط ×1.5 والكبير ×2.
- الإضافات تُجمع بعد تطبيق معامل الحجم، وسعرها لكل بيتزا.
- المنيو التجريبي وأسعاره في `Main`، ومعاملات الحجم في `PizzaSize`.
- رسوم التوصيل 20 جنيه، والاستلام بدون رسوم. زمن التوصيل التقديري ثابت: 30 دقيقة.
- الخصم الافتراضي صفر. يمكن تمرير رسوم ونسبة خصم إلى `PricingService(deliveryFee, discountRate)`؛ النسبة بين 0 و1 وتطبق على الأصناف فقط.
- الحسابات تستخدم `double` كما في UML، مع تقريب المبالغ إلى منزلتين عشريتين.
- ترتيب الحالات: `NEW → PREPARING → READY → COMPLETED`. الإلغاء متاح قبل الإكمال.
- تعديل أصناف الطلب من الكونسول متاح في `NEW`، وبدء التحضير يتطلب نجاح الدفع ووجود أصناف.
- عند الوصول إلى `READY` تُطبع رسالة SMS تجريبية، ويُسند طلب التوصيل إلى خدمة التوصيل.
- الدفع بالكارت محاكاة؛ القائمة تسمح بتجربة قبول أو رفض العملية. لا يتم جمع بيانات كارت أو خصم أموال أو إرسال SMS حقيقي.
- إلغاء طلب مدفوع داخل المحاكاة يُبطل نتيجة الدفع في الكونسول؛ لا توجد خدمة استرداد أموال فعلية.
- يمكن إكمال أو إلغاء الطلب الحالي ثم إنشاء طلب جديد. الرجوع من طلب جديد يلغي هذا الطلب.
